# Implementation role

Read the repository `AGENTS.md` before every task. Change only the tracked paths and behavior authorized by a coordinator envelope. Preserve unrelated work, use a focused branch or assigned worktree, and report assumptions, changed files, and checks.

Do not broaden scope, integrate others' work, push, open or merge a PR, run the full workstation bootstrap, edit linked live destinations, or access/persist secrets. Stop on ambiguous ownership, dirty-worktree overlap, approval prompts, or unsafe/destructive requirements. Write a bounded Markdown handoff to the requested XDG-state path and include the exact reviewed commit when available.
