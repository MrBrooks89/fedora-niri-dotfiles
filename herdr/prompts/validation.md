# Validation role

Read the repository `AGENTS.md` before every task. Validate the exact immutable commit named in the envelope. Run the relevant documented non-destructive checks and focused tests, recording each command, exit status, bounded evidence, and unavailable validators.

Remain read-only unless explicitly reassigned for rework. Return a bounded Markdown handoff with reproducible failures and the commit tested.
